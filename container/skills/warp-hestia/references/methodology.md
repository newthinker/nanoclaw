## 八个概念（判读用得上的那一层）

1. **社融**：实体经济从**整个金融体系**拿到的钱，比「贷款」宽——把企业债、政府债、股票融资、
   委托/信托贷款、未贴现承兑汇票都装进来。`tsf_stock` 是**存量**（欠多少，万亿），
   `tsf_flow_ytd` / `tsf_flow_mom` 是**增量**（新拿到多少，亿元）。分项在 `tsf_flow_*`。
2. **M0 / M1 / M2**：`m0` 是现金；`m1` 是现金 + 活期，代表**交易意愿**；`m2` 是 M1 + 定期储蓄，
   代表**财富总量**。最有预测力的单指标是 **`scissors = m1_yoy − m2_yoy`**：为正 = 钱在活化（热），
   为负 = 钱在沉淀（冷）。⚠️ M1 口径 `2025-01` 起修订过，跨该断点不可直接比。
3. **存款四部门**：`deposit_household_*`（老百姓）、`deposit_corp_*`（公司）、
   `deposit_fiscal_*`（政府收上来没花的）、`deposit_nbfi_*`（券商基金保险理财）。
   **第四项是「存款搬家」的直接证据**——它大增说明钱从银行转去了理财与市场。
4. **贷款的部门与期限拆分**：住户分 `loan_hh_short_*`（消费贷/信用卡/个人经营贷）与
   `loan_hh_mlt_*`（八九成是房贷）；企业分 `loan_corp_short_*`（补流动资金）、
   `loan_corp_mlt_*`（建厂买设备上项目）、`loan_bill_*`（票据贴现）；另有 `loan_nbfi_*`。
   **这张拆分表是后面全部社会判断的原材料。**
5. **票据融资**（`loan_bill_*`）：期限短、办理快、月末季末能迅速做大贷款规模，
   是银行「冲量」的常用工具。⇒ **票据在企业新增贷款里占比越高，真实信贷需求越弱。**
6. **银行间利率**（`rate_ibo` 同业拆借 / `rate_repo` 质押式回购）：金融体系**内部**的资金松紧。
   ⚠️ 银行间利率低 **≠** 实体拿到的钱便宜——利率极低而贷款很弱，说明钱堵在金融体系里出不去。
7. **外储与汇率**（`fx_reserve` / `fx_rate`）：外币存款大增而外币贷款下降，
   通常意味着企业和居民不愿结汇、倾向持有美元。
8. **跨境人民币结算**：贸易项 + 直接投资项的人民币使用额，是人民币国际化的进度条；
   其中 FDI 与 ODI 的对比能看出外资态度。

## 八问框架（叙述骨架，逐问写）

按下面八问顺序组织叙述。**每一问先看字段、再做比较、最后落一句判断**，
并在括号里带上你引用的字段名与数值。括号里的「→ 信号」是这一问对应的四信号，
写完后应与 `## 信号` 段一致；**不一致时以信号段为准，说明你读错了表，不要去改信号段**。

### （一）经济是在扩张，还是在收缩？

- **看**：`deposit_household_*` 与 `loan_hh_short_*` + `loan_hh_mlt_*`（住户存款 vs 住户贷款）。
- **比**：两者的方向组合——存↑贷↑ = 边赚边借，扩张；**存↑贷↓ = 少花少借、预防性储蓄**；
  存↓贷↓ = 收入与现金流都变弱，最差；存↓贷↑ = 加杠杆，要看借的是什么钱。
- **落**：说清居民是「没钱」还是「不敢花、不愿借」。
  ⚠️ 从「存↑贷↓」转成「存↓贷↓」是**显著恶化**的信号（缓冲垫被吃掉），要点名。
- → 无独立信号，是全局底色。

### （二）房地产是否真正复苏？

- **看**：`loan_hh_mlt_ytd` / `loan_hh_mlt_mom`（住户中长期贷款，主体是房贷）的**月均**。
- **比**：月均与 `hh_mlt_monthly_warm` 阈值比；也与前 12 期表里的同期比。
- **落**：这个数是**净额**——已经扣掉了提前还贷。所以它弱不只是「新房贷少」，
  还含「老房贷在被提前还掉」。金融数据在这一问上的优势是**它不会说谎**：
  销售面积和成交金额有口径差异，「居民从银行借走了多少长期贷款」是一笔笔真实的账。
- → `signal_housing`。

### （三）消费到底回暖没有？

- **看**：`loan_hh_short_ytd` / `loan_hh_short_mom`（消费贷 + 信用卡 + 个人经营贷）的**月均**。
- **比**：月均与 `hh_short_monthly_warm` 比；并与 `m0_yoy` 交叉印证。
- **落**：净减少意味着居民**从「借钱消费」退回「用现金消费」甚至不消费**；
  三类（消费贷 / 信用卡 / 个体经营周转）同时萎缩要分开说。
  ⚠️ 若外部社零同比为正而本项在减少，说明**消费靠动用存量储蓄支撑，不是靠信贷扩张**——
  前者不可持续，后者才代表信心。
- → `signal_consumption`。

### （四）企业是在扩张，还是在维持经营？

- **看**：`loan_corp_mlt_*` 与 `loan_corp_short_*` 的对比，以及各自占 `loan_corp_total_*` 的比。
- **比**：中长期 ÷ 短期。中长期增长更快 = 建项目买设备，**真扩张**；
  短期增长更快 = 补现金流，**只是活着**。
- **落**：两个必须追问的点——① 中长期里有多少是**政策驱动**的项目配套
  （结合 `tsf_flow_govt_bond_ytd` 看），那是「政策性投资」不是「企业看好未来」；
  ② 短期的绝对量大说明**经营性现金流紧**（生意好、回款快就不需要借这么多短钱）。
- → 无独立信号，为（五）作铺垫。

### （五）企业贷款增长有没有水分？

- **看**：`bill_ratio` = `loan_bill_*` ÷ `loan_corp_total_*` × 100（`prepare.py` 已算好，**别自己算**）。
- **比**：与 `bill_ratio_healthy` / `bill_ratio_severe` 比。
- **落**：占比越高，冲量成分越重、真实需求越弱。
  ⚠️ **累计口径会平滑掉节奏**：票据冲量集中在月末季末，半年累计看不出来。
  要看细的必须逐月看 `_mom`——单月票据占当月企业新增贷款超过 `bill_ratio_severe`，
  那个月的信贷数据就要打折扣。
- → `signal_credit`。

### （六）钱去哪儿了？—— 存款搬家与资金空转

- **看**：`deposit_nbfi_*`（非银存款）与 `loan_nbfi_*`（非银贷款）。
- **比**：非银存款占存款增量的比重；非银贷款的方向。
- **落**：非银存款大增 + 非银贷款净还 = **存款搬家**，钱进了理财基金券商保证金。
  推力是存款利率太低，拉力是市场的预期回报更高。
  把它与 `m2_yoy`、`rate_ibo` 连起来就是**资金空转**：水位在涨，水没流到田里。
- → 无独立信号，但它是（八）的前半段。

### （七）谁在给经济加杠杆？—— 部门杠杆的转移

- **看**：住户（`loan_hh_*` / `deposit_household_*`）、企业（`loan_corp_total_*` / `deposit_corp_*`）、
  政府（`tsf_stock_govt_bond` / `tsf_flow_govt_bond_ytd`）、非银四个部门放在一起。
- **比**：谁在加杠杆、谁在去杠杆，以及**政府这条腿的发力强度与上年同期比是强了还是弱了**。
- **落**：杠杆从居民向政府转移，短期是**必要的**（居民收缩时政府也收缩会让总需求螺旋下滑），
  中期有**代价**（付息压力挤压未来财政空间）。**关键观察点是能不能传导**——
  政府加杠杆有没有带动居民和企业重新加杠杆；没有传导迹象要明说。
- → 无独立信号，是本框架里最重要的宏观结论。

### （八）钱贵不贵？—— 利率与资金面

- **看**：`rate_ibo`、`rate_repo`。
- **比**：与上期、与上年同期各比一次（两个方向可能相反，都要写）。
- **落**：绝对水平低 = 资金面宽松；边际抬升要区分**正常月度波动 / 半年末因素**与**转向信号**。
  🔴 与（六）连起来：**利率极低 + 实体贷款增速仍弱**，说明核心矛盾不在货币供给端
  （钱不缺、也不贵），而在需求端（没人想借）——这也意味着继续降息的边际效果会越来越弱。
- → `signal_activation` 的背景（活化信号本身由 `scissors` 判定）。

## 五条传导链（跨字段关联的提示）

单个指标只是点，连成链条才成判断。写叙述时用它们把八问串起来。

- **房地产链**：`loan_hh_mlt_*` ↓ → 购房需求弱 → 开发商回款慢 → 房企拿地少 →
  土地出让金少 → 地方财政承压 → 地方债发行需求 ↑（`tsf_flow_govt_bond_ytd` ↑）。
- **消费链**：`loan_hh_short_*` ↓ + `deposit_household_*` ↑ + `m0_yoy` ↑ →
  居民转向现金消费与储蓄 → 消费品企业营收承压 → 企业不敢扩产 → 就业与收入预期走弱 →
  居民更不敢消费（**负反馈**）。打破它的关键不在货币政策，在收入预期。
- **财政替代链**：信贷需求弱 → 银行放不出贷款（`tsf_flow_rmb_loan_ytd` 占社融比重 ↓）→
  财政发债顶上（`tsf_flow_govt_bond_ytd` 占比 ↑）→ 财政支出变成存款（`m2_yoy` ↑）→
  但这些钱不产生新的信贷需求 → **M2 涨而 M1 不涨（`scissors` 为负）**。
  这条链解释「为什么 `m2_yoy` 明显高于贷款增速」。
- **资金空转链**：存款利率低 + 实体回报低 → 存款搬家（`deposit_nbfi_*` ↑）→
  非银资金充裕（`loan_nbfi_*` ↓）→ 涌入债市股市 → `rate_ibo` 维持低位 →
  金融资产价格涨而实体融资不增。这条链解释「为什么『经济数据不好』和『股债走强』能同时发生」。
- **外部链**：外币存款 ↑ + 外币贷款 ↓ → 企业不愿结汇、主动降外币负债 →
  结合 `fx_rate` 与 `fx_reserve` 看 → 再看跨境人民币结算里 FDI 与 ODI 的对比。

## 误读陷阱

写之前逐条自查，这五条每一条都能让一整段结论作废。

1. **口径变更处不做同比。** `caliber_version` 不同的两期不可直接比，尤其 M1 相关的一切
   在 `2025-01` 前后（详见 `glossary.md`）。跨了就明写「口径变更，此处不做同比」。
2. **`_ytd` 与 `_mom` 不混比。** 年初累计和当月增量是两个量。
   ⚠️ **口径是按段的**：同一期里存款段与贷款段可能各用各的，看字段后缀，别贴行级标签。
3. **票据占比高 ≠ 信贷强。** 恰恰相反，它是「冲量」的探针（见八问之五）。
4. **只看总量不看结构。** 社融和 M2 都在涨，不等于钱流到了实体；
   必须拆到分项和部门才知道是谁在借、借去干什么。
5. **单月数据不过度解读。** 单月受基数、节假日、月末冲量影响大；
   趋势要看前 12 期表，别拿一个月的拐点当转向。

## 排版纪律（2026-09-18 追加）

> 🔴 **加这一节的原因**：下面那五条写作纪律全是关于**内容**的，一条都没管**形式**；
> 而「每个判断句后面括注字段与数值」还会把句子撑得更密。实测结果是每问一个
> 450–650 字的块、八个连着，人类读者反馈「阅读很吃力」。**内容对 ≠ 能读**。

**每一问按这个骨架写：**

```markdown
### （一）经济是在扩张，还是在收缩？

**结论：存↓贷↓，收入与信心双重走弱。** 这是四种组合里最差的一档。

| | 本期（8月末累计） | 去年同期 | 变化 |
|---|---:|---:|---|
| 住户存款 | 69900 亿元 | 97700 亿元 | **−28%** |
| 住户贷款合计 | **−10312 亿元** | +7075 亿元 | 由增转偿 |

住户贷款两端同时走弱：中长期 188 亿元（上期 1010，几乎停摆），短期 −10500 亿元。
去年同期是 10800 与 −3725，合计仍为净新增。

⚠️ 本期 `_mom` 字段全部缺失，无法做单月拆分——上表的「变化」只能读累计口径。

<sub>字段：`deposit_household_ytd` / `loan_hh_mlt_ytd` / `loan_hh_short_ytd`</sub>
```

**四条规则：**

1. **开头一句加粗结论，不超过 30 字。** 结论埋在段末的话，读者要读完 600 字才知道你在说什么。
2. **三值以上的对比进小表。** 「69900，低于去年同期的 97700，压缩约 28%」是从句套从句；
   表格一眼可读，数字右对齐后还能横向比。**两值对比留在句子里即可**，别为了表格而表格。
3. **字段名挪到段末的 `<sub>` 行**，不要嵌在句子中间。溯源性一点没丢——要核对时它们在那儿；
   但读的时候不再每隔几个字被一串下划线打断。⚠️ **不是删掉**：字段名是这份笔记区别于
   「聊宏观」的地方，也是核对数字的唯一入口。
4. **论证段不超过 150 字。** 超了就拆。

**缺失与警示**用 `⚠️` 单起一行，别混在论证里——那是读者最需要一眼看到的东西。

## 写作纪律

- **每个判断句后面括注你引用的字段与数值。** 例：
  「居民不愿加杠杆（`loan_hh_mlt_ytd` 月均 369 亿元，低于 `hh_mlt_monthly_warm` 2000）」。
  没有数字支撑的判断句一律删掉——**这是本 skill 与「聊宏观」的唯一区别**。
- **不做预测。** 只写「数据显示了什么」和「接下来该盯什么」，不写「未来会怎样」。
  「需要每月盯的观察点」是可以写的，那是**观察计划**不是预测。
- **主体只写数据。** 让字段和数值做主语（「住户中长期贷款净增 X」），
  不要出现「市场认为」「专家预计」这类**没有出处的第三方主体**。
- **不引入契约与侧车之外的数据。** 需要交叉验证的外部指标（社零、CPI、失业率、
  房价指数、土地出让收入）只能写成「**建议交叉看 X**」，**不要凭记忆填数**。
- **数据缺失就说缺失。** 信号是 `unknown` 时写「本期缺 X 字段，该信号无法判定」，
  不要拿相邻期的值替代，也不要略过不提。
